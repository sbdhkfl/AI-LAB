# AI-LAB Error Messages

AI-LAB errors should be understandable to a beginner.

## Required structure

**What happened:** one sentence.

**Why:** simple explanation.

**Try this:** one concrete action.

**Check:** the expected result.

**Still stuck:** collect the exact command, exact error text, project version, and step number. Remove secrets first.

## Design rules

- Prefer plain English.
- Keep technical error codes for developers.
- Never blame the user.
- Give one safe first fix.
- Do not recommend deleting random files or reinstalling everything first.
- Do not ask a beginner to change several things at once.
- Preserve enough diagnostic information to reproduce the problem.
